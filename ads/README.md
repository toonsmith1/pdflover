# PDF Lover Ads

พื้นที่นี้ใช้แยกระบบโฆษณาออกจากเครื่องมือ PDF หลัก

โครงสร้างที่วางไว้:

- `placements/` ตำแหน่งโฆษณา เช่น หน้าแรกและหน้าดาวน์โหลด
- `campaigns/` ข้อมูลแคมเปญและช่วงเวลาแสดงผล
- `assets/` รูปภาพหรือสื่อโฆษณาที่ตรวจสอบแล้ว
- `uploads/` ไฟล์ที่ผู้ดูแลอัปโหลด (ถูก ignore)
- `reports/` รายงานสถิติที่สร้างอัตโนมัติ (ถูก ignore)

กฎเบื้องต้น:

- โฆษณาต้องไม่บังปุ่มทำงานหรือเนื้อหา PDF
- ต้องแยกโฆษณาออกจากไฟล์ที่ผู้ใช้อัปโหลด
- ห้ามเก็บ API key หรือข้อมูลส่วนตัวไว้ในโฟลเดอร์นี้
- ใช้ `.env` สำหรับค่าตั้งค่าระบบโฆษณาในเครื่องจริง

## ผู้ดูแลคนเดียว

สร้าง token ครั้งเดียวแล้วใส่ใน `.env`:

```bash
openssl rand -hex 32
ADS_ADMIN_TOKEN=วางค่าที่ได้ตรงนี้
```

ดูโฆษณาที่เปิดใช้งานสำหรับหน้าเว็บ:

```bash
curl http://127.0.0.1:8000/api/ads
```

จัดการแคมเปญต้องส่ง header ผู้ดูแล:

```bash
curl -H "X-Ads-Admin-Token: $ADS_ADMIN_TOKEN" \
  http://127.0.0.1:8000/api/admin/ads
```

สร้างหรือแก้ไขแคมเปญใช้ `PUT /api/admin/ads/{id}` และลบใช้ `DELETE` endpoint เดียวกัน ระบบรับเฉพาะ campaign id ที่เป็นตัวอักษร, ตัวเลข, `-` และ `_` เพื่อป้องกันการเขียนไฟล์นอกโฟลเดอร์ ads
