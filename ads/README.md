# PDF Lover Ads

พื้นที่นี้ใช้แยกระบบโฆษณาออกจากเครื่องมือ PDF หลัก

โครงสร้างที่วางไว้:

- `placements/` ตำแหน่งโฆษณา เช่น หน้าแรกและหน้าดาวน์โหลด
- `campaigns/` ข้อมูลแคมเปญและช่วงเวลาแสดงผล
- `assets/` รูปภาพหรือสื่อโฆษณาที่ตรวจสอบแล้ว
- `uploads/` ไฟล์ที่ผู้ดูแลอัปโหลด (ถูก ignore)
- `reports/` รายงานสถิติที่สร้างอัตโนมัติ (ถูก ignore)

กฎเบื้องต้น:

- โฆษณาต้องไม่บังปุ่มทำงานหรือเนื้อหา PDF
- ต้องแยกโฆษณาออกจากไฟล์ที่ผู้ใช้อัปโหลด
- ห้ามเก็บ API key หรือข้อมูลส่วนตัวไว้ในโฟลเดอร์นี้
- ใช้ `.env` สำหรับค่าตั้งค่าระบบโฆษณาในเครื่องจริง
