# Thai Fonts for PDF Lover

This directory contains the **TH Sarabun New** font family created by Suppasit Vongsarnpigoon for the Software Industry Promotion Agency (Public Organization) (SIPA) and the Department of Intellectual Property (DIP), Thailand.

## License

The font files contain the GPL version 2 or later license with a font
embedding exception. A copy of the notice is included in
[`LICENSE-TH-Sarabun-New.txt`](LICENSE-TH-Sarabun-New.txt). Keep both the font
files and this notice together when redistributing the application. The
exception states that embedding the unmodified font (or unaltered portions)
in a document does not by itself make that document subject to the GPL.

The license applies to the font files; it does not change the license of the
PDF Lover application.

The Google Fonts **Sarabun** family is included separately as
`Sarabun-*.ttf`. It is licensed under SIL Open Font License 1.1; the complete
notice is in [`LICENSE-Sarabun-OFL.txt`](LICENSE-Sarabun-OFL.txt). The bundled
files were downloaded from the Google Fonts `ofl/sarabun` directory.

The full-coverage **Noto Sans JP** variable TrueType font is included as
`NotoSansJP[wght].ttf` (about 9.2 MB). It is licensed under SIL Open Font
License 1.1; the license notice is in [`LICENSE-Noto-OFL.txt`](LICENSE-Noto-OFL.txt).
The file was downloaded from Google Fonts `ofl/notosansjp` and is embedded by
ReportLab when the `Noto Sans JP` option is selected.

## Japanese CID fonts

Japanese PDF text uses the bundled `NotoSansJP[wght].ttf` font under SIL OFL
1.1. PDF Lover does not use or package the former Heisei CID font references.

ReportLab is used by the application to generate PDFs. Its BSD license is
included at [`licenses/REPORTLAB-LICENSE.txt`](../licenses/REPORTLAB-LICENSE.txt)
for redistribution compliance.
